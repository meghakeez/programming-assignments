This project implements a Digital Music Manager using a doubly linked list. It supports inserting, deleting, sorting, and shuffling music records stored in musicPlayList.csv.

Features
Insert: Add a new song to the front of the list
Delete: Remove a song by title
Sort: Sort by artist, album, rating, or times played
Shuffle: Generate a random play order without modifying list links

Test Functions
Includes three standalone tests for:
Insert
Delete
Shuffle
